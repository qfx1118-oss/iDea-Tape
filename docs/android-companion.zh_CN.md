# 安卓配套 App

公开开源版 0.6.1 使用安卓系统接口与原生 OpenStreetMap 图块视图，不含专有地图 SDK、地图 Key，不需要 Google 服务或云账号。源码：https://github.com/qfx1118-oss/iDea-Tape 。

## 安装与配对

在安卓 8 及以上安装 Release APK。同签名覆盖更新可保留私有录音；卸载会删除。设备需安装匹配 BLE 固件并保持录音待机，手机点连接、授予附近设备/蓝牙权限，选择 iDea Tape，在安卓配对窗口输入录音笔屏幕上的六位码。旧安卓搜索蓝牙需要定位权限。接收通过显示持续通知的前台服务运行，不再需要时可停止接收。蓝牙传输无需 Wi-Fi 配网。

## 录音与接收

设备仍使用原按键录音。手机边录边接收，结束后请求缺失片段，校验完整音频，同步写入 WAV 与资料，再发送保存确认。只有身份、长度和校验匹配，设备才删除录音。断线、保存失败或确认缺失时保留设备录音。补传已实现，仍需更多断线场景实测。单段设备录音受缓存容量限制；实时传输不等于无限推流或即时监听尚未完成的 WAV。

手机凸起的红色圆点键可独立录音；录音时切换为停止保存方块。设备与手机录音共用私有录音库。收藏持久保存，搜索匹配标题/来源/日期，时间可筛选今天、近 7/30 天及包含首尾日期的自选范围。录音按日期分组，完整列表支持滚动，实心金色星标标明收藏；左滑点垃圾桶删除，5 秒倒计时内可撤销。新自动名称包含来源和本地日期时间；旧默认名称会迁移，手动命名保留。未知开始时间明确使用导入时间。分享 WAV/JSON 显示名称使用标题加稳定后缀，内部录音 ID 不变。

## 可选位置与地图

定位由用户选择开启。实际 START 事件发生时，定位必须在十秒内，否则留空。资料保存 WGS84 经纬度、精度、提供方、采样时间和年龄。只记录起点，不记录轨迹。旧录音导入和中途接入不会伪造起点；界面显示定位就绪和精度，大致定位权限可能只提供粗略坐标。

地图与录音库共用搜索/收藏/日期状态。拖动、双指或按钮缩放；当前区域筛选限制标记及结果列表。“查看全部”解除区域限制并缩放到匹配录音。点标记后选择同位置录音，在 App 内播放；结果列表也能选择，详情保留其他地图入口。没有有效位置的录音仍在录音库。

在线底图默认关闭，明确开启后才联网。原生视图只通过 HTTPS 向 tile.openstreetmap.org 请求当前可见图块，发送稳定应用标识及项目链接，至少缓存七天、对过期图块重新验证，并显示 OpenStreetMap 署名。不需要地图账号或 Key，不提供离线区域预取。正常图块访问为尽力提供，不保证可用性；底图失败仍可用本机标记和回放。见[图块规则](https://operations.osmfoundation.org/policies/tiles/)与[地图署名/许可](https://www.openstreetmap.org/copyright)。

## 隐私与保存

录音、资料和收藏在 App 私有目录，卸载前请先导出重要录音。默认只分享音频，附带位置 JSON 需单独选择。地图服务器可获知 IP 和大致浏览区域；本应用不发送音频、标题或标记资料集。定位可选，没有路线记录或云备份。播放与蓝牙传输不依赖地图联网。权限拒绝、存储满恢复、断线中断和不同品牌后台限制仍需更多手机验收。

## 构建

使用 JDK 17、Android platform 35 和 build-tools 35.0.0：

```sh
python3 tools/build_android.py --jdk /path/to/jdk17 --platform /path/to/android-35 --tools /path/to/build-tools/35.0.0 --keystore /outside/repository/testing.keystore
python3 tools/check_android_package.py build/android/idea-tape-android.apk
```

无需 Gradle 或第三方 Java 依赖。外部签名路径不存在时，脚本创建开发签名；升级需沿用原签名，不要提交私钥。SDK 工具、生成类、DEX 和 APK 放在被忽略的构建目录。协议/音频恢复、录音库/日期/投影的纯 Java 主机测试位于 tests/android。构建成功不等于完成手机渲染或在线地图验收。

## 设备地点显示与删除

在手机录音页先开启“录音起点定位”，再开启“地点名称与设备显示”并阅读单独提示。授予定位权限并保持蓝牙连接。Android 系统地址服务解析当前道路，未返回道路时仅使用实际返回的区或城市；无需地图 SDK 或应用 Key。系统服务可能联网，也可能不可用。解析与音频和蓝牙处理分开，最多每 30 秒请求一次，缓存 60 秒或移动 80 米后失效。只使用 10 秒内的定位；设备 25 秒未收到刷新会清除，断开连接立即清除。设备当前地点仅临时显示；录音库按各录音保存的坐标解析并保存地点名，不会套用手机当前地点，不记录轨迹；关闭开关即可清除。

左滑后点垃圾桶，或从详情及更多菜单删除。当前界面显示 5 秒撤销倒计时，离开应用可能完成删除。撤销期间文件临时移至私有目录，随后删除；重启后超过 60 秒的旧撤销文件会清理。仅保留文件身份、块数和校验凭据，不含音频或 GPS，防止已主动删除且此前已安全保存的录音被延迟补传重新导入。未接收或不匹配的录音不会凭此获得确认。

## 0.6.0 播放与省电管理

磁带采用炭黑外壳、奶油色 Fraunces 粗斜体与橙色细节。「i」上方圆点在待机和播放时为奶白色，录音时为红色。录音库播放进入磁带播放器：播放/暂停、拖动进度、前后跳转 10 秒，并可选择 1、1.25、1.5、1.75、2 倍速。长按磁带临时 2 倍，松开恢复所选倍速；暂停时转轴惯性滑行并回弹。地图保持简洁播放。

蓝牙空闲采用均衡连接，实际接收时提速，保存完成后恢复均衡。空闲清单查询从 5 秒调至 15 秒，重连间隔逐渐退让至 30 秒；接收缓存每 64 块落盘一次，原为 16 块。异常退出可能多补传少量尚未落盘的数据，但删除设备录音前仍必须完整校验、可靠保存 WAV 与资料并完成匹配确认。GPS 请求间隔为 8 秒，网络定位为 30 秒，起点必须在 10 秒内的新鲜度要求不变。只用手机录音时，保存后结束接收前台服务。不可见磁带不持续请求动画帧，可见转轴约 30 帧/秒。

这些调整减少不必要工作，尚不能证明 OPPO Find X8 Ultra / ColorOS 17 上的降温或续航幅度。建议用同样时长锁屏接收，分别关闭和开启定位，对比设置中的电池用量；不建议全面关闭系统电池保护。若后台限制中断锁屏接收，仅检查此应用的后台权限。Android 建议传输后恢复均衡连接：https://developer.android.com/reference/android/bluetooth/BluetoothGatt 。OPPO 电池用量说明：https://support.oppo.com/en/answer/?aid=2171043 。
